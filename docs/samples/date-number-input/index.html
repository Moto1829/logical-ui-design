日付と数値の入力で、形式と単位の迷いをなくす

日付や数値は、形式や単位を誤っても見た目では気づきにくい値です。入力部品の選び方と、受け入れる側の工夫で比べます。

学習トップへ サンプル一覧へ
Bad

悪い例

生年月日をカレンダーで選ばせ、形式の違いをエラーにし、単位を見出しにしか書いていません。

‹2026年10月›
1234567 891011121314

入力形式が正しくありません

  • 生年月日のために、何十年分も月をさかのぼる必要がある
  • ハイフン付きという一般的な書き方がエラーになり、直し方も分からない
  • 単位が見出しにしかなく、円単位で入れて1000倍の金額になっている
Good

良い例

値の性質に合う部品を選び、形式の違いを受け入れ、単位と換算を入力欄の横に置いています。

生年月日
年 月 日

ハイフンはあってもなくてもかまいません

千円

＝ 120万円

申し込み締め切り: 2026年10月31日（土）23:59まで

  • 本人が知っている遠い過去の日付は、直接入力の方が速い
  • 電話番号の形式の違いはシステム側で吸収している
  • 単位が入力欄の横にあり、換算も示されて桁の誤りに気づける
