UI Sample

同じ意味のものを、同じ見た目と言葉にそろえる

画面ごとに見た目や言葉が少しずつ違うと、ユーザーは画面を開くたびに使い方を学び直すことになります。同じサービスの2つの画面を並べて比べます。

Bad

悪い例

同じ青のボタンが保存にも削除にも使われ、日付や用語も画面ごとに違います。

案件一覧

A社 リニューアル10/1
B社 保守契約9/28

プロジェクト詳細

更新日: 2026年9月28日

  • 同じ青が削除と保存の両方に使われ、主要な操作と危険な操作の区別がつかない
  • 「案件」と「プロジェクト」、「10/1」と「2026年9月28日」が混在している
  • ボタンの角の形が画面ごとに違い、同じ部品だと認識しにくい
Good

良い例

役割ごとに決めた共通部品と、共通の用語・日付表記を使っています。

案件一覧

A社 リニューアル2026年10月1日
B社 保守契約2026年9月28日

案件詳細

更新日: 2026年9月28日

color-action-primary
主要な操作
color-danger
危険な操作
color-action-secondary
補助的な操作
  • 色が役割で決まっていて、危険な操作がどの画面でも同じ見た目になる
  • 用語と日付の表記が全画面でそろい、比較や検索がしやすい
  • 部品の形がそろい、一度覚えた使い方を他の画面でも使える
