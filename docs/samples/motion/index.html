UI Sample

動きを、装飾ではなく情報として使う

動きは最も強く注意を引きます。ボタンを押して、動きが理解を助ける場合と、作業を妨げる場合の違いを確かめてください。

学習トップへ サンプル一覧へ
Bad

悪い例

止められない流れる帯、一瞬で消える項目、操作を止める長い演出があります。

秋の大感謝セール開催中！ 全品ポイント5倍！ 秋の大感謝セール開催中！ 全品ポイント5倍！
  • ノート A5
  • ボールペン 3本組
  • 付箋セット
カート 0

  • 流れ続ける帯を止める手段がなく、本文を読む妨げになる
  • 削除した項目が一瞬で消え、どれが消えて何が詰まったのか見失う
  • 1.5秒の演出が終わるまで、他の操作を受け付けない
Good

良い例

お知らせは止められ、削除は短く縮んで消え、カートへの追加は待たせずに知らせます。

秋の大感謝セール開催中（10月31日まで）
  • ノート A5
  • ボールペン 3本組
  • 付箋セット
カート 0

  • 自動で切り替わるお知らせに一時停止があり、動きを控える設定では最初から止まる
  • 削除した項目が0.2秒で縮んで消え、何が起きたかが追える
  • カートの件数が短く強調されるだけで、操作は待たされない

※ 1秒間に3回を超える点滅は、光過敏性発作を起こす危険があるため、このサンプルにも含めていません。
