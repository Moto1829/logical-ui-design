UI Sample

AIの出力を、確認して使える形で見せる

AIの出力は正しいとは限りません。完成品のように見せるか、確認して使う下書きとして見せるかで、誤りが広がるかどうかが変わります。

学習トップへ サンプル一覧へ
Bad

悪い例

要約が本文と同じ見た目で自動挿入され、根拠も取り消し手段もありません。

週次定例 議事録

今週の決定事項: 新料金プランを11月1日に公開する。担当は営業部。問い合わせ対応の体制は現行のまま維持する。

参加者: 佐藤、田中、鈴木

  • 1段落目がAIの要約だと分からず、確認されないまま共有される
  • 何をもとに要約したのか、確かめる手がかりがない
  • 「何でも聞いてください」では、何を頼めるのか分からない
Good

良い例

要約を下書きとして区別し、根拠、採用、再生成、依頼の例を示しています。

週次定例 議事録

✦ AIによる要約の下書き内容を確認してから追加してください

  • 新料金プランを11月1日に公開する（担当: 営業部）議事録 12行目
  • 問い合わせ対応の体制は現行のまま維持する議事録 31行目

対象: この議事録（2,340文字）。添付の資料1件は読み取れませんでした。

  • AIの出力が下書きとして区別され、確認が必要なことがその場で分かる
  • 各要点に元の行へのリンクがあり、対象範囲と読めなかった部分も示されている
  • 採用、編集、再生成、破棄を選べ、依頼の具体例も示されている
