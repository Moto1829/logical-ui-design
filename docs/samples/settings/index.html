設定がいつ、誰に反映されるかを見せる

設定画面はたまにしか開かれません。分類、反映のタイミング、影響の範囲が見えないと、変更が失われたり、意図しない人に影響したりします。

危険な操作

チームを削除すると、すべてのプロジェクトが削除されます。元に戻せません。

  • 分類名が目的の言葉になっていて、久しぶりでも探せる
  • スイッチは即時反映で、反映されたことが知らされる
  • チーム全体に影響する設定と危険な操作が、見出しで分けられている
