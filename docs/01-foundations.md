# 第1章 UI設計の基礎
## 第1章 UI設計の基礎

UIデザインを見た目だけで評価すると、「なんとなく読みやすい」「なんとなく今っぽい」という曖昧な会話になりがちです。ここでは、UIを評価するための最低限の言葉を揃えます。

## 1. UIは視覚表現ではなく、認知と行動の設計

ユーザーは画面を見た瞬間に、次の流れを短時間で処理しています。

1. どこに何があるかを知覚する
2. その意味を解釈する
3. 何をすべきか判断する
4. 実際に操作する
5. 結果を見て次の行動を決める

UIが悪いと、このどこかで余計な負荷が発生します。つまり、UIデザインの仕事は「情報を飾ること」ではなく、「知覚、理解、判断、操作をスムーズにつなぐこと」です。

では、具体的にどこで負荷が増え、何を整えると使いやすさが上がるのでしょうか。次に、認知と身体の両面から基本的な観点を見ていきます。

## 2. 認知心理学の観点

### 認知負荷を増やさない

人は一度に多くの情報を正確に処理できません。ラベルが曖昧、情報のまとまりが弱い、ボタンの優先順位が不明、といった状態は認知負荷を上げます。

悪い状態の例:

- 項目名がplaceholderにしか書かれていない
- 補足説明とエラー表示が混在している
- 強調すべきボタンが複数あり優先度が分からない

良い状態の例:

- ラベルが常に見える
- 入力項目が意味ごとにグルーピングされている
- 主要行動が視覚的に一番強い

### 視線の流れを設計する

ユーザーは画面全体を均等には見ません。大きさ、位置、余白、コントラストによって視線は誘導されます。重要な情報が散っていると、読解に余計な探索コストが発生します。

### 一貫性で学習コストを下げる

同じ見た目には同じ意味、同じ操作には同じ結果が期待されます。一貫性が崩れると、ユーザーは毎回解釈し直さなければなりません。

## 3. 人間工学の観点

### 押しやすい大きさと間隔

ボタンやチェックボックスが小さいと、特にモバイル環境で誤操作が増えます。タップ対象のサイズと周辺余白は、見た目ではなく身体的な操作しやすさに直結します。

### 読みやすい文字とコントラスト

薄い文字色、小さすぎる文字、詰まりすぎた行間は、それだけで読み取りコストを上げます。UIはポスターではなく、短時間で理解される必要のある道具です。

### フィードバックの明確さ

入力が正しいのか、保存できたのか、何が原因で失敗したのかが分からないUIは不安を生みます。操作結果が即座に明確に返ることは、安心して操作できる条件です。

ここまでの観点を踏まえると、良し悪しは流行の見た目ではなく、理解と操作をどれだけ助けているかで判断できます。次は、その違いを悪いUIと良いUIとして整理します。

## 4. 悪いUIと良いUIの見方

悪いUIは、単に見た目が古いUIではありません。次のような状態を指します。

- 情報の優先順位が分からない
- どこを見ればよいか分からない
- 何を入力すればよいか分からない
- 押してよいか不安になる
- 間違えたときに復帰しにくい

良いUIは、その逆です。見た目の装飾量が少なくても、理解しやすく、操作しやすく、結果が予測できるなら良いUIです。

## 5. サンプルで確認する

会員登録フォームを題材に、悪い例と良い例を比較できるサンプルを用意しています。

- [フォームUIの比較サンプル](samples/forms/index.html)

サンプルでは次の違いを確認できます。

- ラベルが常時見えるか
- 入力項目のまとまりが明確か
- 文字の可読性が十分か
- 主要ボタンが明確か
- エラーや補足の扱いが理解しやすいか

こうした点が崩れると、単に使いにくいという感想で終わりません。ユーザーは「理解に時間がかかる」「自分の判断が正しいか不安になる」「間違えたときに戻れないかもしれない」と感じ、操作をためらうようになります。

- 理解が遅れる: 画面の目的や次の行動が分からず、読み直しや探し直しが増える
- 判断が鈍る: どのボタンを押すべきか確信が持てず、操作速度が落ちる
- 不信感が生まれる: 反応や結果が読めないため、サービス自体への安心感が下がる
- 継続利用が弱まる: 小さな迷いが積み重なり、また使いたい気持ちを削る

この章では、UIを評価するための土台となる考え方を整理しました。最後に、以降の章でも繰り返し使うポイントを要点としてまとめます。

## 6. この章の要点

- UIデザインは視覚の好みではなく、認知と行動を助ける設計である
- 認知負荷を減らし、視線誘導と一貫性を整えることが重要である
- 人間工学の観点から、読みやすさと操作しやすさを保証する必要がある
- 良いUIは、速く理解でき、迷わず操作でき、結果が予測しやすい

## 迷いやすい判断

**見た目の新しさと分かりやすさが衝突したとき**

分かりやすさを優先します。流行の表現（境界線のないボタン、薄い灰色の文字など）を取り入れた結果、押せる要素が分からなくなったり、文字が読みにくくなったりするなら、その表現は道具としてのUIの目的に反しています。見た目の新しさは、理解と操作を損なわない範囲で取り入れます。

**「慣れれば使える」画面をどう評価するか**

毎日使う専門的な業務画面では、慣れた人の効率を優先する判断もありえます。ただし、初めて使う人、たまにしか使わない人がいるなら、慣れるまでの負担も評価に含めます。「慣れれば使える」は、慣れるまでに起きる誤操作や離脱を見落としやすい言い方です。

## レビューコメントの例

「入力欄の名前がプレースホルダーにしか書かれていないため、入力を始めると何の欄か分からなくなります。入力欄の上に常に見えるラベルを置くと、入力中も確認しやすくなります。」

「保存ボタンを押しても画面に変化がなく、保存できたかどうかが分かりません。押した直後に『保存しました』と表示すると、二重に押されることや、不安から画面を離れられないことを防げます。」

## 演習

次の画面について、認知心理学の観点と人間工学の観点から、問題点を1つずつ挙げてください。

> スマートフォン向けの会員情報の編集画面。入力欄はすべてプレースホルダーで項目名を示している。画面の下部に、高さ28pxの「保存」と「退会」のボタンが隣り合って並んでいる。

??? note "解答例"
    - 認知心理学の観点: プレースホルダーだけでは、入力中に項目名が消え、何を入力していたかを覚えておく必要がある。常に見えるラベルを置く
    - 人間工学の観点: 28pxのボタンは指で押すには小さく、保存と退会が隣り合っているため押し間違えやすい。ボタンを大きくし、退会は離れた場所に移す
