# 第30章 データ可視化の基礎
## 第30章 データ可視化の基礎

第8章では、ダッシュボードで何を優先して見せるかを扱いました。この章では、その中に置かれるグラフそのものの設計を扱います。グラフは数字を飾るためのものではなく、数字の表だけでは見えにくい違い、変化、関係を、一目で読み取れるようにするためのものです。

## 1. グラフの種類は「何を読み取らせたいか」で選ぶ

グラフを選ぶときは、見た目の好みではなく、読み手に答えてほしい問いから考えます。

| 読み取らせたいこと | 向くグラフ | 例 |
| --- | --- | --- |
| 項目どうしの大小の比較 | 棒グラフ | 部署ごとの売上 |
| 時間による変化 | 折れ線グラフ | 月ごとの利用者数 |
| 全体に占める割合 | 積み上げ棒グラフ、項目が少なければ円グラフ | 問い合わせの種類の内訳 |
| 値のばらつき | ヒストグラム | 対応時間の分布 |
| 2つの値の関係 | 散布図 | 広告費と申込数 |

円グラフは、角度や面積で大きさを比べさせるため、項目が多いと違いを読み取れません。項目が少なく、「半分以上を占める」のような大まかな割合を伝えたい場合に限って使います。正確に比べさせたいなら、長さで比べる棒グラフの方が適しています。

## 2. 軸と基準を正しく置く

グラフの軸の設定は、読み手の印象を大きく左右します。

確認したい点:

- 棒グラフの縦軸が0から始まっている
- 比べるグラフどうしで、軸の範囲がそろっている
- 単位が軸または値の近くに書かれている
- 目標値や前年の値など、判断の基準になる線がある

棒グラフは、棒の長さで大きさを比べさせるグラフです。軸が0から始まらないと、わずかな差が何倍もの差に見えます。折れ線グラフは変化の形を読ませるためのものなので、軸を0から始めなくても問題ない場合がありますが、その場合は軸の値を明示します。

左右に2つの縦軸を持つグラフは、軸の取り方しだいで2つの線の関係を自由に見せられてしまうため、読み手を誤解させやすいものです。2つのグラフに分ける方が安全です。

## 3. 色は意味のあるところにだけ使う

第3章で扱ったとおり、色は意味を補強するために使います。グラフでも同じです。

設計上の示唆:

- 伝えたい系列だけに色を付け、他は灰色にする
- 同じ意味のデータには、どのグラフでも同じ色を使う
- 赤と緑のように、色覚の違いによって区別しにくい組み合わせだけに頼らない
- 凡例を離れた場所に置くより、線や棒の近くに直接名前を書く

凡例を読み取るには、色を覚えて、凡例とグラフの間を目で往復する必要があります。第2章で扱った記憶の負荷を避けるため、可能な限り系列名を線や棒のそばに直接書きます。

## 4. 数値の見せ方をそろえる

グラフと一緒に表示される数値にも、設計が必要です。

基本の考え方:

- 必要以上の桁を出さない（「12,345,678円」より「1,235万円」）
- 比べる数値どうしで、単位と小数点以下の桁数をそろえる
- 表の数値は右寄せにし、桁の位置をそろえる
- 変化を示すときは、何と比べた変化かを書く（「前月比 +12%」）

「+12%」とだけ書かれていると、前月比なのか前年同月比なのか、目標に対してなのかが分かりません。比較の対象が分からない数値は、判断の材料になりません。

## 5. 装飾を減らしてデータを目立たせる

グラフに立体的な表現、影、濃い格子線、背景の模様を加えると、見た目は華やかになりますが、データを読み取る妨げになります。

減らしてよいもの:

- 立体表現: 奥行きによって棒の高さや円の面積が正しく比べられなくなる
- 濃い格子線: 薄い線か、主要な目盛りだけで十分なことが多い
- 枠線や背景色: データとの区別に役立たないなら不要
- 必要以上の目盛り: 読み取りに必要な間隔だけにする

ただし、減らしすぎて数値が読み取れなくなっては意味がありません。判断に必要な数値は、ラベルとして直接書く方がよい場合もあります。

## 6. 良いグラフの条件

- 読み取らせたい問いに合ったグラフの種類を選んでいる
- 軸が誤解を招かず、単位と基準が示されている
- 色が意味のある系列にだけ使われ、色以外でも区別できる
- 数値の桁と単位がそろい、比較の対象が書かれている
- 装飾がデータの読み取りを妨げていない

グラフの設計が崩れると、正しいデータから誤った判断が生まれます。

- 差を誤解する: 軸の取り方で、小さな差が大きく見える
- 読み取れない: 項目の多い円グラフや凡例の往復で、比較をあきらめる
- 意味を取り違える: 比較の対象が分からず、良い変化か悪い変化か判断できない
- 重要な点を見落とす: すべての系列が同じ強さで描かれ、注目すべき変化が埋もれる

グラフは、データから判断までの距離を縮めるための道具です。最後に、この章の要点をまとめます。

## 7. この章の要点

- グラフの種類は、読み取らせたい問いから選ぶ
- 棒グラフの軸は0から始め、比べるグラフの軸をそろえる
- 色は伝えたい系列に絞り、系列名は直接書く
- 数値は桁と単位をそろえ、比較の対象を明記する
- 装飾を減らし、データを読み取りやすくする

## 迷いやすい判断

**グラフで見せるか、表で見せるか**

正確な値を調べたり、1件ずつ確認したりする目的なら表が向いています。傾向、差、変化を一目で把握させたい目的ならグラフが向いています。両方の目的がある画面では、グラフで傾向を示し、その下に表で値を示す組み合わせが有効です。第9章で扱ったテーブルとカードの判断と同じく、ユーザーの作業から選びます。

**グラフに数値ラベルを付けるか**

項目が少なく、正確な値が判断に必要なら、棒の端などに数値を直接書きます。項目が多い場合や、傾向だけを伝えたい場合は、ラベルが重なって読みにくくなるので、マウスを重ねたときに表示する方法や、表を併用する方法を選びます。

## レビューコメントの例

「部署別の売上が10項目の円グラフで表示されており、小さな項目どうしの大小が読み取れません。部署間の比較が目的であれば、売上順に並べた横棒グラフにすると、差と順位が一目で分かります。」

「売上推移の棒グラフの縦軸が900万円から始まっているため、5%程度の増加が2倍以上に見えます。棒グラフは0から始めるか、変化を見せたいのであれば折れ線グラフに変えることを提案します。」

## 演習

次のグラフについて、問題点を3つ挙げ、それぞれの改善案を考えてください。

> 管理画面に、7種類の問い合わせ件数を示す立体的な円グラフがある。各項目は虹色で塗り分けられ、凡例はグラフの下にまとめて表示されている。グラフの上には「+8%」とだけ書かれている。

??? note "解答例"
    - 7項目の円グラフでは大小を比べにくく、立体表現でさらに歪んでいる。件数順に並べた横棒グラフにする
    - 虹色の塗り分けと離れた凡例で、色と項目の対応を覚える必要がある。注目させたい項目だけに色を付け、項目名を棒の横に直接書く
    - 「+8%」が何との比較か分からない。「前月比 +8%（合計 1,240件）」のように比較の対象と元の値を書く
