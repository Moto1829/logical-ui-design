# 第18章 ボタンとアクションの設計
## 第18章 ボタンとアクションの設計

画面上のボタンは、ユーザーが実際に行動を起こす場所です。ここが曖昧だと、それまでの情報設計や文言設計がどれだけ整っていても、最後の一歩で迷いや誤操作が発生します。この章では、優先順位、配置、状態、ラベルの4点からボタン設計を整理します。

## 1. ボタンは装飾ではなく行動の宣言

ユーザーはボタンを見たとき、次の3つを瞬時に判断しようとしています。

1. これを押すと何が起きるのか
2. 今、自分が押すべきものはどれか
3. 押して問題ないのか

この3つに答えられていないボタンは、見た目が整っていても使いにくいボタンです。逆に言えば、ボタン設計とは「結果」「優先順位」「安全性」を見た目と言葉で表現する作業です。

では、優先順位はどう表現すればよいのでしょうか。まず、操作の重みを整理するところから始めます。

## 2. 優先順位は3段階で考える

1つの画面に並ぶ操作は、次の3段階に分けると整理しやすくなります。

- 主要操作: その画面で最も期待されている行動。原則1つ
- 補助操作: 使う人もいるが、主役ではない行動
- 破壊的操作: 削除や取り消しなど、結果が重い行動

この3段階が視覚的に区別されていないと、ユーザーは自分で重みを推測しなければなりません。

悪い状態の例:

- 保存、下書き、削除が同じ強さで横並びになっている
- 塗りつぶしボタンが1画面に4つ以上ある
- 破壊的操作が主要操作と同じ色で表示されている

良い状態の例:

- 主要操作だけが塗りつぶしで、視線が自然にそこへ向かう
- 補助操作は枠線やテキストリンクなど、一段弱い表現になっている
- 破壊的操作は色と位置の両方で分けられている

主要操作を1つに絞れない画面は、多くの場合、画面の目的が絞れていません。ボタンの問題として現れていても、原因は情報設計側にあります。

## 3. 配置と距離で誤操作を防ぐ

視覚的な強さを変えても、破壊的操作が主要操作のすぐ隣にあれば、誤操作は起きます。人間工学の観点では、隣接した対象ほど押し間違えやすくなるためです。

対策の基本:

- 破壊的操作は、主要操作から物理的に離す
- 削除などは一覧の行内ではなく、詳細画面や補助メニューに置く
- 並び順を画面ごとに変えない

第13章で扱った危険操作の設計は、確認ダイアログを足すことよりも、まず「隣に置かない」ことから始まります。

## 4. 押せない理由が分からない無効化を避ける

必須項目が埋まるまで送信ボタンを無効化する設計はよく使われますが、これは「なぜ押せないか」が画面に書かれていない場合、ユーザーを行き止まりに置くことになります。

無効化したボタンは、次の問題を持ちます。

- なぜ押せないのかが伝わらない
- 押しても反応がないため、原因を探す手がかりが得られない
- 色が薄くなることで、そもそも存在に気づかれにくい

代替案としては、ボタンを押せる状態のままにしておき、押したときに未入力箇所を指摘して該当位置へ移動させる方法があります。無効化するにしても、「必須項目を入力すると送信できます」のように、条件を近くに明示します。

## 5. ラベルは操作の結果を書く

ボタンの文言は、押した後に何が起きるかを表すのが基本です。「OK」「はい」「送信」のような汎用語は、文脈を読み直さないと意味が確定しません。

- 曖昧: 「OK」「確定」「実行」
- 明確: 「公開する」「配送先を変更する」「アカウントを削除する」

特に確認ダイアログでは、ボタン文言だけを見て判断されることが多いため、結果を書く効果が大きくなります。文言の考え方は第16章で詳しく扱います。

ここまでの観点を踏まえると、良いボタン設計は装飾ではなく、判断の補助として機能しているかどうかで評価できます。

## 6. 良いボタン設計の条件

- 主要操作が一目で分かる
- 補助操作は使えるが、主役になっていない
- 破壊的操作が色と距離の両方で分離されている
- ラベルから操作結果が予測できる
- 押せない場合は、その理由が近くに書かれている

ボタンの優先順位が崩れると、画面の完成度に関係なく実害が出ます。

- 判断が止まる: どれを押すべきか決められず、操作前に手が止まる
- 誤操作が起きる: 破壊的操作が主要操作と同じ重みに見え、押し間違える
- 主要導線が使われない: 本来使ってほしい行動が埋もれ、利用率が下がる
- 問い合わせが増える: 押せない理由が分からず、操作方法の質問が発生する

ボタンは画面の中で最も小さな要素ですが、行動が発生する唯一の場所です。最後に、この章の要点をまとめます。

## 7. この章の要点

- ボタン設計とは、結果、優先順位、安全性を表現する作業である
- 操作は主要、補助、破壊的の3段階に分けて視覚的に区別する
- 破壊的操作は、見た目だけでなく距離でも分離する
- 無効化するときは、押せない理由を画面上に残す
